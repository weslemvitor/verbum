# Verbum

O Verbum transcreve áudios do WhatsApp Web no navegador. Este repositório contém o site da extensão e o ZIP para instalação manual no Chrome ou no Arc.

Para abrir o site localmente, execute `python3 -m http.server 8080 --directory dist` e acesse [localhost:8080](http://localhost:8080).

O áudio fictício da demonstração foi gerado por [elevenlabs.io](https://elevenlabs.io/) e é usado para fins não comerciais. [Condições de uso da amostra](https://elevenlabs.io/docs/pt/help-center/legal/can-i-publish-the-content-i-generate-on-the-platform)
